CS180 Projects

Taught by Professor Alexei Efros and Professor Angjoo Kanazawa, CS180 explores the fundamentals of computer vision through hands-on projects spanning image processing, computational photography, 3D reconstruction, and modern neural approaches.

Project 0 Intro

Creative Perspectives

Exploring fundamental photography concepts through creative composition: perspective compression, dolly zoom effects, and unconventional framing techniques.

Topics: Photography basics, perspective, composition
Project 1 Image Alignment

Images of the Russian Empire

Colorizing Prokudin-Gorskii's glass plate images through automatic alignment using image pyramids, NCC scoring, and edge-based features for robust registration.

Topics: Image pyramids, alignment, feature detection
Project 2 Frequencies

Fun with Filters and Frequencies

Implementing convolutions, edge detection, image sharpening, hybrid images, and multi-resolution blending using Gaussian and Laplacian pyramids.

Topics: Convolution, frequency analysis, image pyramids
Project 3 Geometry

Homographies & Mosaicing

Creating image mosaics through homography estimation, feature matching (Harris corners, RANSAC), and automated image stitching.

Topics: Homographies, feature detection, RANSAC, warping
Project 4 3D Vision

Neural Radiance Fields (NeRF)

Implementing NeRF from scratch: fitting neural fields to 2D images, camera calibration, ray sampling, volumetric rendering, and novel view synthesis for 3D reconstruction.

Topics: Neural rendering, 3D reconstruction, volumetric methods
Project 5 Generative AI

Diffusion and Flow Models

Exploring diffusion models from using pretrained models (DeepFloyd IF) to training UNets from scratch: denoising, flow matching, classifier-free guidance, and conditional generation on MNIST.

Topics: Diffusion models, denoising, generative modeling, flow matching
