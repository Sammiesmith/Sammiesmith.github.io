Part 1: Fitting a Neural Field to a 2D Image

Implementing the Dataloader

Running neural networks is computationally expensive, particularly when there's a lot of input data. An image with many pixels means that there will be many nodes in the first layer… and a lot more expensive convolutions to compute. To help with this problem, I made a dataloader that reduces image size by randomly sampling a batch of pixels. First, I read in images, then created a meshgrid-based normalized to [0,1] to sample coordinates from. I also normalized colors to [0,1] range so that I can use PSNR loss later in my training loop. Lastly, I wrote a sampling function that randomly samples N pixels from the image by randomly sampling 1) the coords from the meshgrid (then de-normalizing back to image coordinates) and 2) the corresponding colors. Below is a visualization of 100 random pixel samples from the fox image.

Pixel Coordinate Normalization:

\[(x, y) \in [0, W] \times [0, H] \rightarrow (x', y') \in [0, 1] \times [0, 1]\]

where \(x' = \frac{x}{W}\) and \(y' = \frac{y}{H}\)

Color Normalization:

\[RGB \in [0, 255]^3 \rightarrow RGB' \in [0, 1]^3\]

\(RGB' = \frac{RGB}{255}\)

Model Architecture

I used the same architecture as provided in the project specification.

Positional Encoding:

\[\gamma(p) = [p, \sin(2^0\pi p), \cos(2^0\pi p), ..., \sin(2^{L-1}\pi p), \cos(2^{L-1}\pi p)]\]

where \(p\) is the input coordinate and \(L\) is the encoding frequency

Network Function:

\[f_\theta: \mathbb{R}^2 \rightarrow \mathbb{R}^3\]

\(f_\theta(\gamma(x, y)) = RGB\)

Figure 2: Neural field network architecture

Training Hyperparameters:

  • num_iterations: 2000
  • batch_size: 10000
  • learning_rate: 1e-2

Loss Function (MSE):

\[\mathcal{L} = \frac{1}{N}\sum_{i=1}^{N} \|f_\theta(\gamma(x_i, y_i)) - RGB_i\|^2\]

Hyperparameter Sweep on Fox

Observations:

  1. Effect of L value: Too large of an L value blurs the image. I think that this is because we add so many extra values in the positional encoding, we weight the original coordinates less. An extremely low value L=1 gives the best reconstruction, although it can't capture details of fur. When L=5, we lose some of the structure of the fox's face, but we see more details. L=15 completely wipes away the fox's face.
  2. Effect of network width: Inputting more pixels into the neural network gives a better reconstruction. This makes sense: the more pixels to work with, the better we can piece together the original image. In deep learning in general, you can get better results by 1) getting more data or 2) making thoughtful design decisions. In this case, since the task is small and there are more pixels to sample from, I can just get more data. This is usually not feasible on real world problems.
